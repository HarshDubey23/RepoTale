Live site, private repository, or rate limit?

If the project runs somewhere its GitHub page does not mention, give its address and the film will show its pages.

A fine-grained token with read-only access to contents lifts the limit from 60 to 5,000 requests an hour. It stays in this tab's memory and is sent only to api.github.com.
